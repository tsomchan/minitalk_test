# Installation
clone this repo *inside* the minitalk project

# How to use
## 1. run the server program
```
make s
```

## 2. make a test
for example
```
make eng p=[PID]
```

### list of tests
```
make 100
make 25k
make 50k
make 250k
make eng
make jp
make rus
make ukr
make gr
make thai

```
